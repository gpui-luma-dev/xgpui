# shader-lab

Reserved for the local interactive correctness and performance app required by
[#7](https://github.com/gpui-luma-dev/xgpui/issues/7).

The app will exercise static and animated mesh gradients, editable parameters,
layout, clipping, rounded coverage, opacity, overlapping UI, resizing, scale
changes, scene replay, and resource cleanup.

Performance scenarios will compare effects enabled/disabled across viewport
sizes, mesh complexity, and instance counts. Report CPU timings, GPU timings
where available, frame-time distributions, and memory estimates, with warmup
separated from steady state and measurement conditions recorded.

This is a documentation placeholder, not a runnable application. Its manifest,
launch command, and measurement approach will be added with implementation after
design agreement.
