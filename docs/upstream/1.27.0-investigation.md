# GPUI 1.27.0 sync investigation

Investigated on November 6, 2026, on `codex/sync-gpui-1.27.0`, starting at
`8ed97a3`. This initial assessment predates integration. See the
[integration and API review](1.27.0-integration.md) for the implemented result.

Adopt upstream's typed AppKit implementation as the preferred direction, while
porting XGPUI behavior explicitly. Retain our Metal rendering and text extension
integration. Replacing entire Apple backend files would discard substantial local
functionality. The text fixes can largely be merged independently of AppKit.

## Apple backend recommendation

Upstream now uses typed `objc2-app-kit` methods, retained native objects,
`objc2-metal`, and `objc2-quartz-core`. Our AppKit conversion still uses the local
`native_appkit` bridge and many raw message sends. Upstream is a useful replacement
for that binding layer, but not a replacement for all of our backend behavior.

| Area | Integration approach |
| --- | --- |
| AppKit application, menu, keyboard, events, display, window appearance | Start from upstream's typed implementation and reconcile local behavior. All these areas have overlapping edits. |
| Window and platform | Manual behavioral port. Dry-run merge produces 154 conflict blocks in `window.rs` and 49 in `platform.rs`. Preserve color configuration, custom rendering integration, notifications, and local lifecycle fixes. |
| Pasteboard | Prefer typed upstream ownership and method calls, but audit nullable results against our October 31 fixes (`8e27f13`). Our wrapper handles a missing native pasteboard; upstream stores a nonoptional `Retained<NSPasteboard>`. |
| Metal renderer and atlas | Retain our rendering implementation and port upstream improvements selectively. Their 67 and nine conflict blocks reflect both conversion overlap and our additional graphics features. |
| Process information | Adopt upstream's shared `process_info` model; thermal and power callbacks are deferred through the foreground executor and observer removal is tied to ownership. |

Preserve wide-gamut/HDR color behavior, headless rendering/readback, custom draw,
canvas/shader/media surfaces, backdrop and layer caches, GPU resource lifetime
rules, and existing validation hooks. Upstream already uses `objc2-metal`, so our
typed resource interfaces can remain; eliminating duplicate binding glue is the
opportunity. Audit Services menu behavior, nullable pasteboards, and native
method signatures from `8e27f13` individually after replacing the bridge.

Upstream's macOS minimum moves to 12.0. Our Apple shader build still specifies
10.15.7. Update deployment configuration, shader compilation, and documentation
together if that requirement is adopted.

## Text system recommendation

Merge upstream's cache and ownership fixes while preserving XGPUI's missing-glyph
reporting, font fallback controls, rendering modes, and Parley integration.

- The cycle fix pools `CharWidthCache` values instead of `LineWrapper` objects.
  Each live wrapper can retain `Arc<TextSystem>` without the pool retaining the
  wrapper. Upstream includes `pooled_line_wrappers_do_not_retain_text_system`.
- Window-local layout cache state moves to interior mutability without locks;
  `WindowTextSystem` moves from `Arc` to `Rc`. Shared `TextSystem` remains `Arc`
  and retains synchronization where needed.
- Hash-only layout APIs and their cache are removed. No callers were found in
  our extensions or apps. Declarations also exist in the retained Apple mirror.
- Upstream also caches resolved fallback fonts and tests repeated fallback
  resolution. Reconcile this with local font generation and invalidation rules.
- Text-system, line-layout, and core-window overlaps produce only one, two, and
  one textual conflict blocks respectively; line-wrapper merges textually.

## Additional integration scope

The supplied release list does not cover the whole 1.26.2 to 1.27.0 delta:

- List scroll anchoring and provisional item measurement change, including a new
  public readiness callback.
- Subscription storage and pending activation change. The subscriber-set types
  are crate-private, so their public methods are not downstream public APIs.
- Headless Metal creation becomes fallible and the renderer factory becomes safe.
- Native-close callbacks defer App access; upstream includes a reentrancy test.
- OHOS support excludes desktop Linux selection and dependencies for
  `target_env = "ohos"`. The default selector explicitly requires injecting an
  external `gpui-ohos` platform through `Application::with_platform`; this is not
  a bundled, automatically selected OHOS backend.
- Non-destructive credentials are macOS-only in `App` and `Platform`. Atomic
  insertion conflicts on server plus account; it is not a universal credential
  API implemented across every backend.

should not be counted as a separate supported API family.

## Integration and verification order

1. Apply upstream-only source changes and review list/subscription behavior.
2. Integrate core platform identity, keystroke semantics, power pacing, native
   close deferral, and text ownership/cache fixes. Retain local text controls.
3. Replace AppKit binding glue area by area, porting local behavior and audit fixes.
4. Port Metal safety and error-handling improvements while retaining graphics
   features; update shared Apple/iOS consumers and macOS deployment requirements.
5. Update supporting-crate pins, lockfiles, manifests, provenance, and docs with
   the existing sync tools. Preserve independently versioned XGPUI packages.
6. Run host tests and platform validation. Include upstream text-cycle/fallback,
   power pacing, native-close and notification regressions; existing font,
   canvas, gamut, shader, media and headless rendering checks; web host keystroke
   cases; and Linux/Windows compilation on their native runners. OHOS needs an
   appropriate target toolchain and injected backend to validate execution.
7. Review the final concrete public API changes individually with the user,
   as required by the repository instructions, before finalizing or releasing.

Investigation validation: release-sync built with its locked dependencies; both
immutable snapshots normalized successfully; comparison and dry-run merges
completed. No runtime tests were run because this branch has no runtime changes.
