## Packaging

Upstream core gains a versioned Wasm-only development dependency on web, while
web depends on core. The normalizer now localizes it (`gpui_web = { package =
"xgpui-web", path = "../gpui-web" }` in the normalized 1.28.1 core manifest), so
Cargo omits it from the registry manifest. The release plan now rejects any
versioned internal edge, development edges included, that points at a candidate
uploaded later, assuming no candidate version is published yet.
