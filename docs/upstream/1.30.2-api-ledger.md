# GPUI 1.30.2 public API ledger

Package 01 of [issue #458](https://github.com/gpui-luma-dev/xgpui/issues/458). Entries describe incoming changes compared with xgpui's published surface and propose a disposition. The package 07 review at the end of this ledger records the implemented surface and the decisions awaiting approval.

## Paths, scene, and geometry

| Incoming API | Purpose and compatibility | Migration and placement |
| --- | --- | --- |
| Non-generic `Path`; removal of generic `Path<P>`, `PathId`, `PathVertex<P>`, `PathVertex_ScaledPixels`, and the old path constructor, mutation, scaling, and triangle methods | Moves path ownership from the triangle scene model to curves. Source-breaking for signatures, struct literals, and writable vertices. | Keep the existing contract. Store tiled data separately inside core. The direct brush and its tests read and mutate vertices. |
| `PathBuilder::build`, removed `PathBuilder::build_path`, and `Window::paint_path` | The new builder returns the curve path and the renderer accepts it. Source-breaking for consumers in xgpui-curve, xgpui-svg, and xgpui-shader. | Keep existing signatures and the legacy builder. An extension adapter could use an additive core curve or mask input in a future change. |
| `FillOptions`, `StrokeOptions`, `FillRule`, `Transform`, `LineCap`, `LineJoin` | Moves options from Lyon tessellation types to GPUI-owned records and uses lyon_path exports. Source/type-identity break for the options. Additional re-exports can affect wildcard imports. | Keep current option types and translate in the internal tiled path route. Review any new exports separately. |
| `Scene::paths`, `PathCurve`, `PathPaint`, `PathTile`, `PaintedPath` and its `new`, `tile_count`, `append_to` | Replaces the public triangle vector and adds curve tile upload records. Field type and host/shader layout compatibility are separate concerns. | Keep public scene storage. Use private renderer records for uploads. These records belong with core and its backends. |
| `Scene::push_layer` and `Window::paint_layer` | Removes bounds arguments. Source-breaking for current line and paragraph painting and downstream callers. | Keep both signatures and their ordering semantics. Use private inferred-bounds helpers where appropriate. |
| `Shadow::{shape_bounds, shape_corner_radii, inset}` | Renames public element fields and changes inset from `u32` to `PaddedBool32`. Breaks struct literals and can affect host/shader layout. | Preserve the public shadow record and translate for upload. Core renderer concern. |
| `PaddedBool32::as_bool` | Reads the padded boolean as a Rust bool. Additive method. | Keep private if only the renderer uses it. No caller migration. |
| `quad_depth_scale`, `quad_depth` | Shares depth mapping across backends. Additive functions. | Keep behind the renderer boundary if feasible. No application migration. |
| `Bounds::join` | Unions bounds with empty-bounds handling. Additive method. | Core geometry if exposed. No migration. |
| `Sum<ScaledPixels>` and `Sum<&ScaledPixels>` for `ScaledPixels` | Enables typed sums for bounds and placement math. Additive trait impls with possible inference impact. | Core-owned type requires a core impl. No planned caller migration. |

These path and scene records have a shader or public Rust compatibility surface. This audit identifies no persisted serialization contract for them. Verify layouts and downstream construction separately from serde behavior.

## SVG and animation

| Incoming API | Purpose and compatibility | Migration and placement |
| --- | --- | --- |
| `Svg::with_timed_transformation`; `TimedTransformation` with `new`, `rotation`, `from`, `to`, `with_easing`, scale/translation/rotation/alpha easing setters, `alternate`, and `with_max_fps` | Configures transforms that advance at presentation time. Additive source APIs. | Core scene and scheduler support is needed. Keep xgpui's executor clock. No existing call-site migration. |
| SVG `Easing` and the animation `heartbeat` helper | Selects interpolation and provides a heartbeat curve. Additive exports where re-exported. Check wildcard imports against extension easing types. | The transform contract may need core easing. A standalone curve can live in an extension. |
| `Transformation::alpha`, `with_alpha`, and `From<Transformation> for TimedTransformation` | Builds SVG poses with opacity and converts a fixed pose into the timed type. Additive methods and conversion. | Core if part of the timed pose. Existing pose constructors remain valid. |
| `MonochromeSprite::animation` replacing `pad`; `SpriteAnimationId` and `NONE` | Ties a sprite to retained animation. The public field change breaks literals and must agree with GPU layout. | Keep public sprite layout and put animation identity in private renderer state if practical. |
| `SvgTextFont` and `SvgRenderer::measure_text_width` | Measures one line using SVG font selection. Additive type and method. | Consider extension placement if it can share the renderer's font setup. No existing migration. |
| `SvgRenderer::parse_svg`, `render_parsed`, and `render_single_frame` return errors, plus `ImageCacheError::Usvg` and `From<usvg::Error> for ImageCacheError` | Package 02 preserves the public usvg 0.46 error type and XML error payload. Internally, GPUI parses and renders with 0.49. There is no serialized error contract. | Existing callers keep their usvg 0.46 dependency and signatures. GPUI carries 0.46 with default features disabled for the error boundary. The SVG lab checks the public type as a downstream caller. |

No stable serialized representation is proposed for the added animation or measurement types.

## Registry helper type identity

Package 02 advances the existing exact helper pins together. Consumers using GPUI's re-exports such as `SharedString`, `Refineable`, and scheduler types can keep their imports. Consumers that share helper types or traits across a direct dependency boundary, including `HttpClient`, need to resolve the same 1.30.2 helper package on both sides. The pin change does not itself change any serialized format. These shared types remain part of the core dependency contract.

The upstream signature would break existing two-argument calls. | Package 03 retains `centered(size, cx)`. Explicit callers can still compose `WindowBounds::Windowed` with `Bounds::centered(display_id, size, cx)`. Core owns default placement. |

The placement, chrome, notification, and test hooks do not propose a new serialized format.

## Package 07 review of the implemented epic

Reviewed the [epic diff](https://github.com/gpui-luma-dev/xgpui/compare/bc849b7743a329d96cdcfa5940a685ddd27c7139...76eb3875de11fb274f0eef1bcce3af0482d45098) from the first parent of the package 01 merge through the package 06 merge. The investigation's earlier baseline `7395879` predates the unrelated #457 merge. This review uses the actual epic fork. The proposed dispositions below await maintainer approval.

### Platform and test APIs

Each row is additive and requires no existing caller migration. Public trait additions have defaults. Downstream code with an identically named extension trait method may need a qualified call.

| Actual item | Purpose and contract | Proposed placement |
| --- | --- | --- |
| `App::active_display` | Returns the active window's display when known. No serialized state. | Core owns display and window placement state. |
| `FocusHandle::is_rendered` | Checks the most recently rendered dispatch tree for the handle. No serialized state. | Core owns the dispatch tree. |
| `Window::set_native_titlebar_visibility` | Requests native titlebar visibility. The package supplies the macOS implementation. No serialized state. | Core effect, with chrome policy left to extensions. |
| `PlatformWindow::set_native_titlebar_visibility` | Backend hook with a no-op default, preserving existing implementors. No serialized state. | Core platform trait. |
| `HeadlessAppContext::simulate_window_scale_factor_change` | Drives the backing test window scale factor. No serialized state. | Core test support, alongside the existing TestAppContext method. |
| `TestAppContext::simulate_window_decorations_change` | Drives the backing test window decoration callback. No serialized state. | Core test support. |
| `TestWindow::simulate_decorations_change` | Simulates decorations at the backend level. The type is in a private module but can be inferred from the feature-gated `PlatformWindow::as_test` return. No serialized state. | Core test backend. |
| `App::debug_state` | Returns diagnostic JSON for the app, displays, windows, and platform. Keys cover compositor, thermal and power state, appearance, cursor, active window, window stack, primary display, displays, windows, and platform details. Consumers should tolerate missing or changed fields. | Core collects state. Extensions can format it. |
| `Platform::debug_state` | Supplies platform-specific diagnostic JSON, with a null default. macOS provides activation, visibility, window numbers, and low-power information. Same unstable schema policy. | Core platform trait. |
| `PlatformWindow::debug_state` | Supplies backend-window diagnostic JSON, with a null default. macOS reports visibility, frame, scale, frame source, callback, and cursor state. Same unstable schema policy. | Core platform trait. |

The per-window JSON collector and macOS display-link debug methods are internal. No direct backend API is added by those implementations.

### Timed SVG API

These additions introduce no serialized format. Existing callers keep their signatures, including `Svg::with_transformation` and `Window::paint_svg`. Approve these in core if retained animation is a supported GPUI feature. An extension cannot update the retained scene's sprite state or its capture revisions through the current extension boundary.

| Actual item | Purpose and contract |
| --- | --- |
| `Svg::with_timed_transformation` | Attach a timed pose. Reduced motion displays the starting pose. |
| `TimedTransformation` | Retained repeating transform descriptor. |
| `TimedTransformation::new` | Create a descriptor with a period. |
| `TimedTransformation::rotation` | Build a full clockwise turn per period. |
| `TimedTransformation::from` | Set the starting pose. |
| `TimedTransformation::to` | Set the ending pose. |
| `TimedTransformation::with_easing` | Apply one easing to all pose channels. |
| `TimedTransformation::with_scale_easing` | Set easing for scale. |
| `TimedTransformation::with_translation_easing` | Set easing for translation. |
| `TimedTransformation::with_rotation_easing` | Set easing for rotation. |
| `TimedTransformation::with_alpha_easing` | Set easing for alpha. |
| `TimedTransformation::alternate` | Traverse both directions within a period. |
| `TimedTransformation::with_max_fps` | Set a cap for animation-only presentation. The least restrictive active cap in a window wins. |
| `Easing` | Select `Linear`, `Quadratic`, `EaseInOut`, `EaseOutQuint`, or `Heartbeat`. A downstream import collision can be resolved by qualifying the type. |
| `Transformation::alpha` | Construct an SVG opacity-only pose. |
| `Transformation::with_alpha` | Set SVG opacity on an existing pose. |
| `From<Transformation> for TimedTransformation` | Convert a static pose to a fixed descriptor. Downstream ambiguous conversion sites can annotate the destination type. |

`Transformation` gains private alpha state that now participates in its derived equality and Debug output. Existing constructors set it to 1. The standalone heartbeat helper and SVG text measurement API did not land in the audited range. The heartbeat easing exists inside the timed implementation.

### Renderer-facing APIs

These items cross crate boundaries to the native renderers. They have no serialized format and require no caller migration. Approve the doc-hidden hooks as shared renderer interfaces. An extension cannot provide these hooks to the existing platform crates without a core bridge.

| Actual item | Purpose and contract |
| --- | --- |
| `PathCurve` | Doc-hidden curve upload record. C layout is 40 bytes. Public fields carry endpoints, coefficients, winding sign, and padding. Derives Clone, Copy, Debug, and PartialEq. |
| `PathTile` | Doc-hidden tile upload record. C layout is 56 bytes. Public fields carry paint index, curve range, backdrop winding, extent, reference point, and curve bounds. Derives Clone, Copy, Debug, and PartialEq. |
| `PathTilePaint` | Doc-hidden paint upload record. C layout is 112 bytes. Public fields carry bounds, content mask, color, fill rule flag, and padding. Derives Clone and Copy. |
| `PathTiles` | Doc-hidden retained tile collection re-exported from core. Derives Debug and Default. |
| `PathTiles::even_odd` | Read the fill rule. |
| `PathTiles::tiles` | Borrow tile upload records. |
| `PathTiles::curves` | Borrow curve upload records. |
| `Path<ScaledPixels>::winding_tiles` | Retrieve optional stock-path winding data. |
| `Path<ScaledPixels>::winding_tile_paint` | Build the renderer paint record for an eligible stock path. |
| `PathVertex<P>: PartialEq` | Compare original and edited triangle geometry. The trait addition is public and leaves the vertex layout intact. |

`Path<P>` retains public vertices and bounds. Its private winding state changes its derived Debug output and Rust in-memory size. Neither is a persisted format. The public legacy path, shadow, sprite, and scene records and the bounded layer entry points remain available.

### Dependency type identity and protected APIs

| Actual item | Purpose, compatibility, and migration |
| --- | --- |
| `gpui::http_client` | The re-export resolves to the 1.30.2 package. Code passing a directly imported `HttpClient` across the GPUI boundary must use the matching version or the GPUI re-export. Core must own the dependency alignment. |
| `SharedString` and the core shared-string re-exports | Resolve to the 1.30.2 helper. Existing GPUI imports remain valid. Align direct helper pins where the types cross the core boundary. |
| `Refineable` and the core refineable re-exports | Resolve to the 1.30.2 helper. Use the matching package for direct trait and derive imports that interact with GPUI, or retain core imports. |
| `RunnableMeta` and scheduler types used by core or backend interfaces | Resolve to scheduler 1.30.2. Align direct scheduler dependencies where types cross backends or core. |
| `ArcCow` and public helper types from the updated util dependency | Resolve to util 1.30.2. Prefer the GPUI re-export where offered and align direct imports crossing the boundary. |
| `SvgRenderer::{parse_svg, render_parsed, render_single_frame}`, `ImageCacheError::Usvg`, and `From<usvg::Error> for ImageCacheError` | Retain usvg 0.46 error identity under a renamed Cargo dependency. The 0.49 rasterizer handles SVGZ internally. Existing error matches and typed calls keep the 0.46 package. The SVG lab verifies the return type, conversion, and parsing error payload. |

The helper update does not declare a serialization change. The published dependency identity is part of the framework contract even when a signature's spelling stays the same. Private backend dependencies and internal shader changes add no application API.

### Compatibility decisions to carry forward

- Preserve two-argument `WindowBounds::centered`, unit-returning notification dismissal, the Lyon builder option types, generic `Path<P>`, `PathId`, `Scene::paths`, and the Apple legacy path exports.
- Keep the existing `MonochromeSprite::pad` and GPU layout. Timed animation metadata travels through retained scene state.
- Leave upstream `SvgTextFont`, `measure_text_width`, `Bounds::join`, the `ScaledPixels` sum impls, and renderer diagnostic getters outside this integration unless separately approved.
