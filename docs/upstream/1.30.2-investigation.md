### How the comparison was produced

1. Build `xgpui-release` with `cargo build --locked --release --manifest-path tools/release-sync/Cargo.toml --target-dir target/release-sync`.
2. Run [`review prepare`](README.md#review-a-release) twice with `--expected-sha` set to the exact gpui-unofficial commits above. Use separate ignored output directories and the checked-in crate name map. The 1.30.2 run also writes provenance for the pinned Zed context.
3. Compare the union of both captures and the committed local Git tree over `gpui`, `.cargo/config.toml`, and `upstream.json`. Exclude the staging mirror. Use Git blobs for local files, normalize CRLF to LF for known text files, and normalize capture package-directory separators before classifying paths. The comparison covers contents. Windows executable-bit and symlink fidelity need separate checking if upstream changes either.
4. For changed Rust and shader files present in all three inputs with distinct signatures, run `git merge-file -p` with local, baseline, and incoming content in that order. Discard merged output. A clean trial establishes textual compatibility only.

The unadjusted Windows report hashed the CRLF checkout against LF captures and marked all 67 modified incoming paths classified as metadata as local overlaps. It also used backslashes in normalized package paths, so the classifier labeled crate source as metadata. The committed comparison corrects these inputs without changing release tooling. Do not use the raw Windows report to apply this import.

## Text merge and behavioral risks

Eleven of 32 shared source files have textual conflicts. The other 21 merge textually. The largest conflicts are Metal renderer (43 regions), core scene (9), and wgpu renderer (5). The remaining eight have one region each. The [comparison](1.30.2-comparison.json) lists every file and result.

- **Scene and render passes.** Depth optimization and batching must keep retained replay and ordering across backdrop captures, custom draws, shader brushes, and offscreen or wide-gamut targets. The stock WGSL already contains the premultiplied-alpha uniform. The host-side blend selection still needs reconciliation. D3D11's single textual conflict does not measure the scope of ordering and ABI changes. [Depth pass](https://github.com/zed-industries/zed/pull/66811) · [Batching](https://github.com/zed-industries/zed/pull/66810)
- **Paths.** The new tiled curve path replaces vertex-triangle rendering upstream. xgpui uses the existing intermediate rasterizer for shader masks on Metal, D3D11, and wgpu, and its direct brush reads public path vertices. Keep both call paths working while adding internal tiled rendering. [Path rewrite](https://github.com/zed-industries/zed/pull/66809)
- **SVG and text.** The SVG renderer has a textual conflict. Port the filter fix with its dependency bump, and keep the existing parsed SVG APIs. The text-line conflict intersects paint-layer changes and local text behavior. Verify text ordering with paragraph painting, glyph handling, and retained replay. [Filter crash fix](https://github.com/zed-industries/zed/pull/67423)
- **Platform and tests.** Keep local Apple frame delivery, Windows CPU COLR and GPU-loss handling, Linux diagnostics, and the local test-context scale-factor simulation. The upstream scale-factor method adds the separate headless entry point. [Headless forwarding](https://github.com/zed-industries/zed/pull/67113)

## Cargo and registry helpers

Eight normalized crate manifests change upstream. The core manifest also moves resvg/usvg to 0.49, enables usvg's `svgz` feature, replaces the Lyon umbrella dependency with lyon_path and a lyon_extra dev dependency, and adds tiny-skia-path for tiled paths. Apple enables the `MTLDepthStencil` binding, macOS adds serde_json for diagnostics, and wgpu adds a Web dependency on js-sys. The normalized Windows manifest changes helper pins and reorders declarations. Keep the Lyon API and dependency surface needed by legacy path callers. The three local-only Cargo paths are the macros and platform manifests and the Web example manifest.

The capture retains the same 17 helper package identities, with the normalized helper release pin moving from `=1.29.3` to `=1.30.2`. The current root lockfile uses 14 of those identities. A Git tree comparison of the published captures found source edits in `path`, `util`, and `zlog`. Those three are outside the current root lockfile. Package 02 should check all affected lockfiles and actual registry resolution, including SVG type identity, before advancing the baseline.

See the [API ledger](1.30.2-api-ledger.md) and [change accounting](1.30.2-accounting.md). No framework or backend builds or runtime checks were performed in this investigation.
