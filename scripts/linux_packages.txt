# System packages for building and running xgpui on Linux (#389).
# Read by scripts/linux_setup.sh (what to install) and scripts/linux_doctor.sh
# (what to check). docs/LINUX-SETUP.md explains each group.
#
# The debian column mirrors the apt-get lists in .github/workflows/*.yml; when
# CI's list changes, change the matching row for every distribution here.
# Distribution detection and the RHEL/openSUSE/Arch notes follow Zed's
# script/linux, but Zed's own extras (libgit2, sqlite, libva, musl) are left out.
#
# Columns, separated by |:
#   group    base, luma (GTK 3 for xgpui-luma) or headless (window probes)
#   check    how linux_doctor.sh verifies it; a leading ? makes a miss a warning:
#              pc:<module>   pkg-config --exists <module>
#              cmd:<name>    <name> is on PATH
#              lib:<soname>  ldconfig knows <soname>
#              icd           a Vulkan driver JSON exists in .../vulkan/icd.d
#              portal        the xdg-desktop-portal service binary exists
#   fedora   Fedora, RHEL, CentOS Stream, Rocky, Alma (dnf)
#   debian   Debian, Ubuntu, Mint, Pop!_OS (apt)
#   suse     openSUSE Leap and Tumbleweed (zypper)
#   arch     Arch, Manjaro, EndeavourOS (pacman)
#   purpose  shown by the doctor
# A package column may list several names separated by spaces; - means none.
#
