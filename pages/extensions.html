2. Wide-gamut presentation

use gpui::WindowColorMode;

// During window construction or an update outside drawing:
window.set_color_mode(WindowColorMode::WideGamutSdr)?;
let status = window.color_status();

// Explicit producer output; legacy paints and controls remain sRGB:
MetalWideSdrOutput::from_linear_p3_premultiplied(context, texture, commands)?;

xgpui-gamut produces bounded linear-P3 SDR surfaces. GPUI backends own window negotiation and composition; Metal and native D3D11 presentation are implemented. Windows native execution/display validation remains outstanding; Linux is deferred.

The browser compares interpolation and gamut mapping as an sRGB preview. Its runtime panel reports source space, mapping, actual canvas color space (or unknown) and browser-reported wide-gamut capability (at least P3).

cargo run --locked --config .cargo/validation.toml --manifest-path apps/xgpui-ext-lab/Cargo.toml --bin color-lab

The native companion pairs mapped sRGB and Display P3 swatches using the same 32 reference samples per row. Check effective WideGamutSdr and display support, then compare on your wide-gamut monitor. Display capability does not verify calibration.

3. Parley text

Shared text backend with flat-LTR compatibility, BiDi paragraph layout and editing/IME geometry. Precise font axes and feature inspection use existing GPUI caches and the glyph atlas. Font-controls labs/tests are verified on macOS and Windows; Linux acceptance remains separate.

xgpui-parley →

Construction, paragraphs, precise axes, preview policy, cache and face identity, supported subset and validation.

Variable fonts and OpenType inspection →

Weight, width, slant and optical size; inspection, native/Parley lab, backend support and core 3.0 migration.

4. Progressive SVG

Experimental full-color static SVG elements with preview/detail refinement, shared FIFO admission and aggregate image accounting. Native lab and attributed offline samples; smaller budgets reduce deep-zoom detail.

xgpui-svg — experimental →

Use SvgImage and SvgScheduler, understand accounting limits, and run the native sample.

5. Standalone color math

xgpui-color provides color conversions, gamut mapping, OkLab/OkLCh interpolation and reusable WGSL helpers with zero runtime dependencies in its default configuration. Optional ICC parsing adds a parser dependency. Use it without GPUI or a GPU context.

xgpui-color: standalone color math →

CPU types, browser runtime diagnostics, native P3 comparison, dependency boundaries and validation.
