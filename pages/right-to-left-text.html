How-to. Hebrew, Arabic and mixed text in a GPUI app: plain GPUI text by default, typeset() when you need an explicit direction.

Right-to-left text

With Parley as the text system and one call to install_text_layout, ordinary GPUI text handles right-to-left and mixed text: div().child("…"), StyledText, tooltips, list rows and third-party widgets. Each paragraph's direction comes from its first strong character. Reach for typeset() only when the text can't decide for itself, for example a string that starts with Latin in a right-to-left UI.

Not released yet. This needs the release after XGPUI 4.1.0 (xgpui-parley after 0.7.0), tracked in #332. Until then, depend on the repository.

Example

A complete app: Parley as the text system, plain GPUI text whose direction comes from the text, and typeset(…).rtl() for a Latin-first string in a right-to-left UI.

Highlighted lines are what XGPUI adds to a standard GPUI app; everything else is ordinary GPUI. The gpui and gpui-platform dependencies are XGPUI's packages of them (xgpui, xgpui-platform).

[dependencies]
# Until the next release: the repository (packages xgpui, xgpui-platform, xgpui-parley).
gpui = { package = "xgpui", git = "https://github.com/gpui-luma-dev/xgpui" }
gpui-platform = { package = "xgpui-platform", git = "https://github.com/gpui-luma-dev/xgpui" }
xgpui-parley = { git = "https://github.com/gpui-luma-dev/xgpui" }
parley = { version = "=0.12.0", default-features = false, features = ["std", "complex-scripts"] }
anyhow = "1"

use anyhow::Context as _;
use gpui::{
    App, Application, Bounds, Context, SharedString, Window, WindowBounds, WindowOptions, div,
    prelude::*, px, rgb, size,
};
use parley::fontique::{Blob, Script};
use std::sync::Arc;
use xgpui_parley::{ParleyTextSystem, install_text_layout, typeset};

// The app's fonts: a Latin UI font and a font that covers Hebrew.
const FONTS: [&[u8]; 2] = [
    include_bytes!("../fonts/IBMPlexSans-Regular.ttf"),
    include_bytes!("../fonts/NotoSansHebrew.ttf"),
];

const HEBREW: &str = "טקסט עברי ארוך עובר לשורה הבאה, והמילים הראשונות נשארות בשורה העליונה מימין.";
const MIXED: &str = "Release notes: גרסה 4.2 זמינה עכשיו";

fn main() -> anyhow::Result<()> {
    // 1. Parley as the text system, with a fallback font for Hebrew.
    let mut fonts = parley::FontContext::new();
    for data in FONTS {
        fonts
            .collection
            .register_fonts(Blob::new(Arc::new(data.to_vec())), None);
    }
    let hebrew = fonts
        .collection
        .family_id("Noto Sans Hebrew")
        .context("Noto Sans Hebrew is not registered")?;
    fonts
        .collection
        .append_fallbacks(Script::from_bytes(*b"Hebr"), std::iter::once(hebrew));
    let parley = Arc::new(ParleyTextSystem::new(fonts, "IBM Plex Sans")?);

    // Why not `gpui_platform::application()`? It is
    // `Application::with_platform(current_platform(false))`, which uses the
    // platform's own text system (CoreText, DirectWrite, …). To use Parley,
    // take the same platform (`false`: windowed, not headless) and give GPUI
    // the text system too, before it builds its text caches.
    let platform = gpui_platform::current_platform(false);
    Application::with_platform_and_text_system(platform, parley.clone()).run(
        move |cx: &mut App| {
            // 2. Lay out plain GPUI text with Parley (also installs `typeset()`).
            install_text_layout(parley.clone(), cx);

            let bounds = Bounds::centered(None, size(px(620.), px(460.)), cx);
            cx.open_window(
                WindowOptions {
                    window_bounds: Some(WindowBounds::Windowed(bounds)),
                    ..Default::default()
                },
                |_, cx| cx.new(|_| RightToLeft),
            )
            .expect("open window");
            cx.activate(true);
        },
    );
    Ok(())
}

struct RightToLeft;

impl Render for RightToLeft {
    fn render(&mut self, _: &mut Window, _: &mut Context<Self>) -> impl IntoElement {
        let heading = |text: &'static str| div().text_sm().text_color(rgb(0x6b7280)).child(text);
        let boxed = || div().w(px(260.)).p_2().bg(rgb(0xf3f4f6));
        div()
            .size_full()
            .p_6()
            .flex()
            .flex_col()
            .gap_3()
            .bg(rgb(0xffffff))
            .text_color(rgb(0x111827))
            .font_family("IBM Plex Sans")
            .text_size(px(16.))
            // 3. Default: plain GPUI text. Each paragraph's direction comes
            //    from its first strong character.
            .child(heading("Default: plain GPUI text"))
            .child(boxed().child(HEBREW))
            .child(boxed().child(MIXED))
            .child(boxed().line_clamp(2).text_ellipsis().child(HEBREW))
            // 4. Right to left: `typeset()` sets the direction explicitly, for
            //    text that starts with Latin in a right-to-left UI.
            .child(heading("Right to left: typeset(…).rtl()"))
            .child(boxed().child(typeset(SharedString::from(MIXED)).rtl()))
    }
}

Bundle your own font files: the example uses IBM Plex Sans for the UI and Noto Sans Hebrew for Hebrew. The repository copy of this example is text-lab/examples/right_to_left.rs; run it with just rtl-example.

  1. Text system. ParleyTextSystem (xgpui-parley) is built from a Parley FontContext and passed to Application::with_platform_and_text_system (xgpui). append_fallbacks tells Parley which font covers Hebrew when the UI font doesn't.
  2. Plain text. install_text_layout (xgpui-parley) registers a TextLayoutProvider (xgpui) with the app, so GPUI's text elements are laid out by Parley. It also installs the engine behind typeset().
  3. Default. The Hebrew paragraph wraps in reading order with its first words at the top right. The mixed string starts with Latin, so it reads left to right. The clamp keeps two lines and ends with an ellipsis.
  4. Right to left. typeset(MIXED).rtl() (xgpui-parley) lays out the same mixed string as a right-to-left paragraph, as a Hebrew UI would show it.

Default: direction from the text

With install_text_layout, every plain GPUI text element is laid out by the same engine as typeset():

  • Direction: each paragraph uses its first strong character. Text with none, such as numbers alone, is left to right.
  • Wrapping: lines follow reading order, and mixed-direction runs are reordered on every line (the Unicode Bidirectional Algorithm).
  • Clamps and truncation: line_clamp and all three text_overflow modes keep the logical start, end or both, and the ellipsis follows the direction.
  • Alignment: text_align left and right act as start and end, so they mirror for right-to-left text.
  • Hit testing: TextLayout::index_for_position and position_for_index (xgpui) answer from the paragraph layout, so InteractiveText clicks and hovers land on the right characters.
  • Styles: highlights, runs, colors, backgrounds, underlines and strikethroughs work as before.

Explicit direction: typeset()

Use typeset() (xgpui-parley) where the text alone gives the wrong direction or language:

use xgpui_parley::typeset;

// A Latin-first label in a right-to-left UI.
div().child(typeset("Release notes: גרסה 4.2").rtl())
// Language-specific shaping and line breaking.
div().child(typeset("تقرير الإيرادات").rtl().language("ar".parse()?))
// Styled ranges, as on StyledText.
div().child(typeset(text).with_highlights(highlights))

.rtl(), .ltr() and .direction(TextDirection::…) set the base direction; .language(…) sets the content language. It inherits the same text style as plain text. Without a Parley engine installed, it renders as plain GPUI text, so components can use it unconditionally.

Without install_text_layout

On native text systems, or on Parley without install_text_layout, plain GPUI text stays on GPUI's flat lines. Single-line right-to-left and mixed labels, per-run styles and end truncation work. Wrapped right-to-left text puts its lines in painting order, and carets and selection inside right-to-left runs follow left-to-right rules. Use typeset() or the paragraph API for those cases. To switch back at runtime, call App::clear_text_layout_provider (xgpui).

Cost

Measured with just text layout-cost: a release build on the Parley backend, macOS (Apple silicon), 180 plain text elements per frame (labels, wrapped paragraphs and truncated cells).

FrameGPUI's flat linesWith install_text_layout
Cold (all new text)3.2 ms3.8 ms (about 1.15×)
Warm (same frame again)0.50 ms0.57 ms (about 1.12×)
Reflow (width changes)0.59 ms0.56 ms (0.95×)
