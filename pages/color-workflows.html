Wide gamut is not another name for P3

Wide gamut describes the ability to represent colors beyond a smaller reference gamut, commonly sRGB. Display P3, Adobe RGB (1998) and Rec.2020 name particular color spaces. A wide-gamut display does not necessarily cover every color in any of them.

Use “wide-gamut window” when discussing the presentation capability. Use “Display P3” when declaring P3 source pixels, storage, producer output or the Metal composition coordinates. There is no Adobe RGB window mode to select. The native renderer converts supported sources into its composition space; the OS display pipeline and the panel determine the visible result.

Follow the pixel through the boundaries

  1. Interpret. Supply the source primaries, transfer and alpha meaning, or a resolved custom definition from supported ICC bytes.
  2. Decode and adapt. Evaluate the declared curves in linear light and adapt the declared XYZ reference to D65 where needed.
  3. Choose storage and mapping. Select P3 or Rec.2020 and a mapping policy. Associate alpha and generate linear-light mipmaps after that choice.
  4. Compose. Native wide placement converts storage primaries into the renderer's composition space. Metal uses extended linear P3; Windows uses extended linear sRGB/scRGB.
  5. Present. Request the window mode and inspect its effective status. The OS maps the result for the actual display.

Changing the source interpretation changes the color represented by identical RGB numbers. Changing storage or output mapping changes how that color is represented or reduced. Changing a display-capability flag does not reinterpret the source numbers.

A practical first check

Open the pixels + metadata demo, keep Mid gray selected and change the interpretation. Then open the chromaticity demo and compare the outlines and hatched mapping regions. Use the native lab when you need to test wide composition or GPU readback.

For mathematical definitions and numerical contracts, continue to the color math reference. The workflows here require no derivation of color-matching functions or chromatic adaptation matrices.
