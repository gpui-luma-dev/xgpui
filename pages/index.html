Upstream source baseline: gpui-unofficial release/1.27.0. XGPUI packages use independent versions.

Why XGPUI?

XGPUI adds richer graphics, text and rendering features through opt-in extensions and small integration seams, keeping changes to GPUI’s public API focused and minimal. The aim is to make those features easier to evolve while keeping upstream updates from Zed and gpui-unofficial straightforward to adopt.

Extensions

xgpui-canvas
Experimental native spatial viewport, f64 camera and retained BVH scenes.
xgpui-color
Standalone CPU color conversions and reusable WGSL math; zero runtime dependencies by default, with optional ICC parsing.
xgpui-gamut
Explicit linear-P3 SDR content producers; normal GPUI controls retain sRGB semantics.
xgpui-gpu-interop
Experimental zero-copy GPU interop: show frames from your own GPU engine in xgpui windows.
xgpui-media
Large images, color adjustments and GPU-backed video previews for GPUI.
xgpui-parley
Opt-in Parley/HarfRust text shaping, BiDi paragraphs and grayscale rasterization.
xgpui-shader
Opt-in gradients, mesh paints, portable WGSL and selectable kinetic typography.
xgpui-shell
Experimental desktop-aware window frames and app-composed title bars.
xgpui-svg
Experimental full-color progressive SVG elements with optional shared raster scheduling and aggregate image accounting.

Core

gpui
Application model, entities, windows, elements, input, layout, text and scene primitives.
gpui-macros
Procedural macros for GPUI actions, elements, contexts, styling and test/benchmark support.

Platforms & rendering

gpui-apple
Shared Apple rendering and services, gated for macOS or iOS.
gpui-ios
Upstream-derived UIKit backend for iOS application lifecycle, windows, touch and native text input; currently versioned as xgpui-ios 1.26.5.
gpui-linux
Linux/FreeBSD platform integration with Wayland and X11 feature paths.
gpui-macos
macOS windows, input, display and native platform integration.
gpui-platform
Selects and constructs the native or web platform.
gpui-web
Browser windowing, input and rendering with WebGPU and a WebGL2 fallback.
gpui-wgpu
GPU context, renderer, atlas and text support used across platform backends.
gpui-windows
Windows native platform, Win32 windows, DirectWrite and DirectX integration.
