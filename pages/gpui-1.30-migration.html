GPUI 1.30.2 migration

GPUI 1.30.2 is available from the XGPUI main branch. The integration PR records the approved API changes and CI results. Its source is the pinned gpui-unofficial 1.30.2 capture.

Align direct helper dependencies

If your app passes types from a directly imported helper crate across the GPUI boundary, use that helper at version 1.30.2 or import the GPUI re-export. Code that already uses the GPUI re-exports can keep its imports.

BoundaryMigration
Shared strings and refinementUse GPUI's SharedString and Refineable re-exports, or align the direct helper crates to 1.30.2.
HTTP clients and scheduler typesUse gpui::http_client or the matching published helper crates. Align a direct scheduler dependency when scheduler types cross the GPUI or backend boundary.
Typed SVG errorsKeep usvg 0.46 when naming the error returned by SvgRenderer or carried by ImageCacheError::Usvg. The rasterizer uses 0.49 internally and supports SVGZ.

Existing path and platform callers

Keep using Path<P>, PathBuilder::build, PathBuilder::build_path, and Window::paint_path. Existing shader brush masks, direct brushes, and paths with manually edited vertices keep triangle coverage. Eligible stock fills and strokes use tiled rendering behind the same APIs.

Existing calls to WindowBounds::centered and notification dismissal keep their signatures. Platform trait implementations can use the defaults for the new titlebar and diagnostic hooks.
