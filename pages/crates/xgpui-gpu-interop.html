Public surface at a glance

EngineSurface, SurfaceSlot, SurfaceDesc, SurfaceFormat, SurfaceStats, SyncPoint, HeavyEngine and the wgpu-feature WgpuSurfaceTarget adapter; IOSurface/MTLSharedEvent on macOS, opaque-fd memory and timeline semaphores on Linux, shared D3D12 textures and fences on Windows.

Dependencies

Dependencies, optional features and target conditions are declared in Cargo.toml ↗.

The first release requires the additive backend hooks in xgpui-apple 4.1.0, xgpui-wgpu 2.3.0 and xgpui-windows 2.2.0. Existing applications need no source migration. The optional wgpu feature enables the engine adapter; Linux and Windows require it for the transport.
