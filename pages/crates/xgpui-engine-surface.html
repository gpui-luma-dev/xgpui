Public surface at a glance

EngineSurface, SurfaceSlot, SurfaceDesc, SurfaceFormat, SurfaceStats, SyncPoint, HeavyEngine and the wgpu-feature WgpuSurfaceTarget adapter; IOSurface/MTLSharedEvent on macOS, opaque-fd memory and timeline semaphores on Linux, shared D3D12 textures and fences on Windows.

API documentation

Not published to crates.io yet, so there is no docs.rs page; the guide's API reference covers the public surface. For full rustdoc, run cargo doc --open --manifest-path extensions/crates/xgpui-engine-surface/Cargo.toml locally.
