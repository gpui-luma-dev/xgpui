Why curves

GPUI can draw a curve: give PathBuilder the control points and it tessellates the path. Everything before and after that is up to you. There are no splines that pass through your data points, no way to ask where a curve is (its nearest point, its length, whether the pointer is on it), no variable-width strokes, and nothing to keep handles smooth while someone edits them.

That gap shows up in ordinary features: a chart line you can hover, a mesh gradient whose wires you can drag, a pen tool, a path that draws itself in along its length, a colour field that follows a curve. Each app ends up hand-writing its own Bézier math. xgpui-curve is that math, written once and tested, with a gpui feature that hands the result back to PathBuilder.

Example: a hoverable chart line

In plain GPUI you would compute every segment's control points yourself and still have no way to tell whether the pointer is on the line. Here the line passes through every sample without overshooting, and one call finds the point under the pointer:

use xgpui_curve::geom::nearest_on_path;
use xgpui_curve::kurbo::Point;
use xgpui_curve::series::{SeriesCurve, series_path};

// A smooth line through every sample that never overshoots the data.
let samples = [Point::new(0.0, 0.9), Point::new(0.25, 0.85), Point::new(0.5, 0.2), Point::new(0.75, 0.25), Point::new(1.0, 0.6)];
let line = series_path(&samples, SeriesCurve::MonotoneX);

// Where is the line under the pointer, and is the pointer on it?
let pointer = Point::new(0.42, 0.5);
if let Some(hit) = nearest_on_path(&line, pointer) {
    let snap_to = hit.point; // put the crosshair or tooltip here
    let hovering = hit.distance < 0.02;
}

Paint line with gpui_paint::stroke_path. The same nearest_on_path works for any path: mesh wires, node outlines, SVG data.

Public surface at a glance

Modules geom, measure, series, func, mesh, spine, node, shape, stroke, fit, svg_path and gpui_paint; types MeshLattice, CurveSpine, NodePath, FunctionalCurve, Easing, MeasuredPath, PathEffect, Squircle, ArcShape and StrokeProfile; the CURVE_SPINE_WGSL and CURVE_SPINE_MSL shader sources; kurbo re-exported as xgpui_curve::kurbo.

Dependencies

Dependencies and features are declared in Cargo.toml ↗.

It always depends on kurbo 0.13, whose types are part of its public API. The default gpui feature adds xgpui for the path adapters; every other feature is plain Rust and builds for wasm32-unknown-unknown.
