← Extensions to GPUI

Paint and shader extension. Opt in through xgpui-shader; ordinary output is sRGB, with explicit native wide-SDR programs.

Paint GPU validation

The paint GPU suites run locally through just test on each host. There are no paint CI workflows; they were removed in #364 because they only ran when someone started them. Rust 1.99.0, .cargo/validation.toml, and committed standalone lockfiles define the build. All Cargo commands use --locked.

Run the suites

just test                                # every suite for this host, paint suites included
just test --list                         # suite names
just test --only paint-lab-portable      # one suite (Windows)
just test --only wgpu-coverage-cache     # Vulkan on Linux, DX12 on Windows

On Windows, the paint suites cover the portable paint lab on DX12, native D3D11/WARP brush parity and a headless DX11 mesh capture. On Linux they run the wgpu coverage-cache and custom-draw tests on Vulkan. Steps covered by other suites are not repeated: paint-lab wgpu checks run in labs, brush tests in shader, and gpui-windows coverage, DX11 and wide-gamut tests in windows-backend.

Command inventory

.github/paints/commands.tsv lists the acceptance commands (tab-separated: backend, scope, name, command), and .github/paints/run.sh selects a backend and scope and runs them. scripts/test_all.sh carries the same paint suites; keep the two lists in step. To check the orchestration without a GPU:

bash .github/paints/run_selftest.sh
bash .github/paints/run.sh --backend windows-native --scope full --dry-run
