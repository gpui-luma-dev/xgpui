Migration guides

Each GPUI upstream sync that changes XGPUI's public API has a guide. Start with the newest one for the version you're moving to; if you're skipping releases, work through each guide in between, oldest first. Since GPUI 1.29.3, a guide lists only the changes that stop existing code from compiling; behavior changes and new APIs are in What's new.

The recorded source baseline is gpui-unofficial release/1.30.2.
