Source examples & developer harnesses

GPUI source-gallery demos

These examples are not published on this site. Links open their source in GitHub. The standalone gallery source contains the local build configuration.

  • Hello world — basic layout and styling.
  • Styled text — typography, font sizes and line heights.
  • Text layout — alignment, decorations and font weights.
  • Text wrapping — wrapping, truncation and CJK text.
  • Text input — typing, cursor movement and selection.
  • Dynamic fonts — fetch a fallback font on missing-glyph notifications.
  • Prime sieve — background workers and progress updates.

Developer Wasm test harnesses

Source modules invoked by browser tests; these are not interactive hosted demos.

  • Font fallback tests — missing-glyph notifications and font preservation.
  • Worker queue stress tests — shared priority queues and real worker contention.
  • Fetch worker tests — streamed response-body contention across workers.

The Color / Gamut demo uses standalone xgpui-color math. Native wide-gamut presentation still requires Metal or D3D11.
