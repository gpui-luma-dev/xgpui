# Contributing

Contributions are welcome: useful enhancements, bug fixes, tests and documentation.
For larger changes, open an issue first so we can discuss the direction.

Fully AI-generated code is welcome. We care about the value and quality of the
contribution, regardless of who—or what—wrote it. You are responsible for the code
you submit: understand it, review it, test it and be ready to address feedback.

Keep pull requests focused. Explain the problem, what your change does and how
you verified it. Follow the existing style, add meaningful tests where appropriate
and update documentation when behavior changes. See
[Local Development](docs/LOCAL_DEVELOPMENT.md) for build and test instructions.

By submitting a contribution, you agree that it is provided under the
repository’s [Apache License 2.0](LICENSE).

This is open source. Let's spend our energy making the project better.
